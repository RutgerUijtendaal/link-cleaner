Privacy policy

Link Cleaner removes tracking parameters from supported links on the pages you browse. The work happens on your device.

Effective 18 October 2026

No browsing-data uploads. No analytics. No stored browsing history.

What the extension accesses

Link Cleaner reads link destinations and the text inside link elements on websites where Chrome allows it to run. It uses this information to identify supported YouTube URLs, remove known tracking parameters, and update matching visible URL labels. It also watches for links and link text added or changed by the page.

This processing happens temporarily in the page on your device. The extension does not use Chrome's browsing-history API or read form fields, passwords, cookies or clipboard contents.

What is stored or shared

The extension does not retain link URLs, page content or browsing history. It does not send this information to the developer or any third party. It contains no analytics, advertising, telemetry, accounts or remote processing, and makes no network requests of its own.

Data accessed by the extension is used only to clean links. It is not sold, used for advertising, transferred to third parties or used to determine creditworthiness. Its use complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Why access across websites is needed

YouTube links can appear on any website. Access to ordinary HTTP and HTTPS pages lets Link Cleaner find and clean those links automatically, including links that appear as a page updates. The extension does not change unrelated destinations.

You control site access through Chrome's extension settings. You can restrict it to selected sites, disable it or uninstall it at any time. Restricting access also restricts where automatic cleaning can work.

What this policy covers

This policy covers the Link Cleaner extension. Following a link still sends a normal browser request to the destination website, whose own privacy practices apply. Removing URL parameters does not prevent other forms of tracking.

This policy page is hosted by GitHub Pages. GitHub may process technical request information, such as your IP address, when you visit this page, under the GitHub Privacy Statement. This page adds no analytics, cookies or third-party embeds.

Changes and questions

Changes to the extension's data handling will be reflected here with an updated effective date. The policy's revision history is available in the repository.
